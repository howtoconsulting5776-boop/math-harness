# Math Solving — 수학 풀이 작성 규약

수학 풀이의 가치는 **정확성 × 학년 적합성 × 단계 명료성**이다. 정답만 맞으면 안 되고, 그 학년 학생이 따라올 수 있는 도구로, 빠짐없는 단계로 풀어야 한다.

## 1. 문제 판독 (먼저 한다)
- **텍스트:** 분수·지수·괄호·부등호·단위를 정확히 해석한다. `3x^2`와 `(3x)^2`, `1/2x`의 모호함을 의식하고, 모호하면 가장 표준적 해석을 택하되 명시한다.
- **이미지(사진):** Read로 이미지를 읽어 문제문·보기·그림·표를 모두 추출한다. 손글씨·인쇄 혼재, 그림 속 치수·각 라벨을 놓치지 않는다. 도형이면 math-geometer에 작도를 넘긴다.
- 판독 불가(흐림·잘림·조건 누락)면 추측해 풀지 말고 무엇이 안 보이는지 보고한다.

## 2. 수준·단원 식별
요청에 학년이 없으면 문제 난이도로 추정하고 **가정을 명시**한다("중2 수준으로 풉니다"). 단원을 한국 2022 개정 교육과정에 정렬한다(상세 매핑·**학기 단위 도구 해금표**는 `references/curriculum-map.md`).

**학원 진도 우선:** `references/academy-profile.md`에 학원 주력 과정·학년별 현재 진도·풀이 스타일이 있으면 먼저 읽어 반영한다. 프로필과 표준 교육과정이 다르면 **프로필을 우선**(학원의 실제 진도가 진실). 프로필이 비어 있으면 표준 표로만 판단한다.

핵심 원칙 — **학년 도구 제한:**
| 학교급 | 쓸 수 있는 도구 | 피할 도구 |
|---|---|---|
| 초등 | 그림·수직선·표·구체물, 사칙연산, 분수/소수, 비와 비율 | 미지수 문자(x), 음수, 방정식, 좌표 |
| 중등 | 문자와 식, 일차/이차방정식, 함수, 합동·닮음·피타고라스, 확률 통계 기초 | 미적분, 삼각함수, 로그 |
| 고등 | 함수·미적분·삼각·지수로그·벡터·확률분포 | 학년·과목 범위 밖 대학 도구 |

학년 도구를 벗어난 빠른 풀이가 있어도, **학년 내 풀이를 주(主)로** 제시한다. 범위 밖 풀이는 "참고: 고교에서는…"으로 분리.

## 3. 풀이 프레임 — 4단계 (하우투수학 시그니처)
모든 풀이를 아래 **4단계 골격**으로 쓴다. 답만 내는 게 아니라 **문제를 푸는 사고 습관**을 학생이 가져가게 하는 것이 목적이다(어떤 단원·문제에도 전이되는 틀). `academy-profile.md`가 다른 프레임을 지정하면 그것을 따른다.
1. **구하는 것** — 문제가 최종적으로 무엇을 묻는지 한 줄로 또렷이 한다.
2. **주어진 것** — 명시·암시된 조건·수치·관계를 빠짐없이 나열한다(그림·단위 포함).
3. **주어진 것을 이용하기** — 주어진 것들로 무엇을 끌어낼지 식·관계를 세워 전개한다. 여기서 실제 계산이 일어난다.
4. **배운 것과 연결하기** — 이 문제가 닿는 개념·공식·정리(배운 것)를 밝히고 그것으로 마무리한다.

3·4 안의 계산은 **풀 수 있는 가장 작은 단계**로 쪼개고, 각 단계 = `무엇을 한다` + `왜(근거: 공식·성질·정의)`. 근거 없는 "계산하면" 금지, 중간식 생략 금지(검산·학습 가능성). 마지막에 **자기검토**: 정의역/조건·단위·차원·특수값 대입·답의 타당성(음수 길이·확률>1 등)을 점검한다.

## 4. 표기법
- 본문 수식은 읽기 쉬운 인라인 표기(`x^2`, `√2`, `1/2`, `≤`)를 쓴다. LaTeX가 필요한 환경이면 `$...$`.
- 분수는 가급적 기약, 무리수는 유리화, 각은 단위(°/rad) 명시.
- 최종답은 한 줄로 분명히(`∴ x = 3`).

## 5. 개념 설명 모드
특정 문제 없이 개념 설명 요청이면: **정의 → 직관(왜 그런가) → 대표 예제(직접 풀이) → 흔한 오개념 → 한 줄 정리** 순. 정의를 던지고 끝내지 않고 반드시 예제로 보여준다.

## 6. 검산 연계
당신의 풀이는 math-verifier가 sympy로 독립 재계산해 대조한다. 그러므로:
- 기호·수치를 명확히 써서 재현 가능하게 한다.
- 가정·정의역을 표면화한다(verifier가 같은 전제로 계산하도록).
- verifier가 FAIL을 보내면 지적 단계만 고친다.

## 출력 형식
```
## 문제
[재진술]
## 수준·단원
[학년 / 교육과정 단원]
## 풀이
**1. 구하는 것** — [무엇을 묻는가]
**2. 주어진 것** — [조건·수치·관계 나열]
**3. 주어진 것을 이용하기**
   1) [무엇을] — [왜]
   2) ...
**4. 배운 것과 연결하기** — [닿는 개념·공식·정리로 마무리]
## 정답
∴ [답]
## 핵심 개념·공식
- ...
## 자기검토
- 정의역/단위/특수값: ...
```

> 교육과정 단원 매핑·도구 해금 시점은 `references/curriculum-map.md`, 학원 진도·스타일은 `references/academy-profile.md`를 읽는다.
