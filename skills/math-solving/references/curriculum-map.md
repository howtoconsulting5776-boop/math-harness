# 한국 2022 개정 교육과정 — 수학과 단원 매핑

> math-solver가 문제를 단원에 정렬할 때 참조. 학년 도구 제한과 단원명을 빠르게 찾기 위한 표. 완전 망라가 아니라 자주 나오는 단원 위주이며, 세부는 교과서판마다 조금씩 다를 수 있다.

## 초등학교 (1~6학년) — 5개 영역
수와 연산 / 변화와 관계 / 도형과 측정 / 자료와 가능성 / (전 학년 공통 과정)

| 학년 | 주요 내용 |
|---|---|
| 1~2 | 100까지 수, 덧셈·뺄셈, 곱셈 입문, 길이·시각, 분류·표 |
| 3~4 | 곱셈·나눗셈, 분수·소수 입문, 평면도형(각·삼각형·사각형), 들이·무게, 막대·꺾은선 그래프 |
| 5~6 | 약수·배수, 분수·소수의 사칙연산, 비와 비율·백분율, 넓이·부피(직육면체·원), 비례식, 평균·가능성 |

도구 제한: **문자식·음수·방정식·좌표 사용 금지.** 미지수는 □·○ 또는 그림·표로.

## 중학교 (1~3학년)
| 학년 | 단원(예) |
|---|---|
| 중1 | 소인수분해, 정수와 유리수, 문자와 식, 일차방정식, 좌표평면과 그래프(정비례·반비례), 기본 도형·작도, 평면·입체도형, 통계(도수분포) |
| 중2 | 유리수와 순환소수, 식의 계산, 일차부등식, 연립일차방정식, 일차함수, 삼각형·사각형의 성질, 도형의 닮음, 확률 |
| 중3 | 제곱근과 실수, 다항식의 곱셈·인수분해, 이차방정식, 이차함수, 삼각비, 원의 성질, 대푯값과 산포도(표준편차) |

도구 제한: 미적분·삼각함수·로그·벡터 금지. 피타고라스(중2 닮음 이후~중3), 삼각비(중3)는 학년 확인.

## 고등학교
| 과목 | 단원(예) |
|---|---|
| 공통수학1·2 | 다항식, 방정식과 부등식(복소수·이차·연립), 경우의 수, 행렬, 도형의 방정식, 집합과 명제, 함수와 그래프(유리·무리·합성·역함수) |
| 대수 | 지수·로그(함수 포함), 삼각함수, 수열 |
| 미적분Ⅰ | 함수의 극한·연속, 미분(다항함수)·적분(다항함수) |
| 미적분Ⅱ | 수열의 극한, 여러 함수의 미적분(지수·로그·삼각) |
| 확률과 통계 | 순열·조합, 확률, 통계적 추정(정규분포·신뢰구간) |
| 기하 | 이차곡선, 평면벡터·공간도형·공간좌표 |

도구 제한: 과목 범위를 넘는 대학 수준(엡실론-델타 형식증명, 선형대수 일반 등) 금지.

## 사용 지침
1. 문제의 핵심 연산·개념으로 학년을 좁힌다(예: "이차방정식 근의 공식" → 중3).
2. 학생이 명시한 학년이 단원의 표준 학년보다 낮으면, 그 학년 도구로 푸는 우회 풀이를 찾거나 "이 문제는 보통 N학년에서 배웁니다"라고 알린다.
3. 단원명은 문제 분류·문제은행 태깅에도 쓴다.
